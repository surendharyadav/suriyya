# PurpleMerit War Room 🛡️

**Multi-agent system for production launch decisions**

## 🎯 Features
- 4 specialized agents (PM/Data/Marketing/Risk)
- Real ML tools (Isolation Forest, t-tests, sentiment)
- Live 10-day dashboard + 21 feedback entries
- JSON/YAML structured output
- Full decision traceability

## 🚀 Run in 30 seconds

```bash
pip install -r requirements.txt
python main.py
```
